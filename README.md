# Kanban Lite

A simple Kanban board built with React.
This project was created to practice component architecture, state management, and interactive UI.

---

## Features

* Create, edit and delete tasks
* Move tasks between columns
* Drag & drop support (works badly on mobile)
* Search and filter tasks
* Data persistence with localStorage

---

## 🧱 Tech Stack

* React
* TypeScript
* Tailwind CSS
* dnd-kit (for drag & drop)

---

## 📁 Project Structure

```
src/
  components/ # React Components
  data/ # Mock data
  hooks/ # Custom hooks
  pages/ # Parts of page
  types/ # Custom types for TS
  utils/ # Utility functions
  App.jsx
  index.css
  main.jsx
```

---

## Getting Started

Install dependencies:

```
npm install
```

Run the development server:

```
npm run dev
```
